## 개요

MeS(Meta Solution)는 연구단의 도시홍수 해석·예측 모형들을 하나의 체계로 묶어 자동으로 구동하고,
그 결과를 3차원 디지털트윈 가상환경과 대시보드로 사용자에게 제공하는 플랫폼입니다. (주)베이지안웍스가 개발했습니다.

각 기관이 개발한 모형은 입력 형식과 구동 방식이 서로 다릅니다. MeS는 관측 자료 수집부터 강수 예측, 침수 해석, 피해·회복력 평가, 화면 표출까지를
10분 주기로 이어서 실행하여, 개별 모형의 결과가 실제 재난 대응에 쓸 수 있는 정보가 되도록 합니다.

- 대상 지역: 서울 도림천 유역, 강남 우수관망 (테스트베드)
- 운영 주기: 10분 (실시간), 강우사상 단위 (사후분석)
- 제공 방식: 웹 기반 서비스 (Chrome 권장) 또는 기관 서버 설치형

## 시스템 구성

```mermaid
flowchart LR
    SRC["외부 자료<br/>기상청 · 한강홍수통제소 · 서울시"]
    COL["수집 모듈<br/>(Collectors)"]
    DB[("통합 DB")]
    SIM["모형 구동 모듈<br/>(Simulators)"]
    VIS["가시화 모듈<br/>3D 디지털트윈 · 대시보드"]
    USER["사용자<br/>재난상황실 · 하수도 · 방재 부서"]

    SRC -- OpenAPI --> COL --> DB
    DB --> SIM --> DB
    DB --> VIS --> USER
```

수집 서버, 모의 서버, DB 서버로 나누어 24시간 자동 운영합니다.

### 1. 수집 모듈 (Collectors)

기상청, 한강홍수통제소, 서울시 등이 OpenAPI로 제공하는 자료를 주기적으로 받아 통합 DB에 쌓습니다.
자료는 정시 기준으로 표준화하고, 오측·결측을 보정하여 모니터링과 모형 구동에 바로 쓸 수 있게 합니다.

| 프로그램 | 수집 자료 | 주기 |
|---|---|---|
| `IUF.Collector.KMA_AWS` | 기상청 AWS 강우 관측 (1분·10분) | 10분 |
| `IUF.Collector.KMA_HSR` | 기상청 HSR 레이더 | 10분 |
| `IUF.Collector.KMA_Grid` | 기상청 고해상도 격자 강수 (NetCDF4) | 10분 |
| `IUF.Collector.SOA_RS` | 서울시 하천 수위 | 10분 |
| `IUF.Collector.SOA_DP` | 서울시 하수관로 수위 | 10분 |

### 2. 모형 구동 모듈 (Simulators)

각 기관의 모형을 정해진 주기에 맞춰 자동으로 실행합니다. 입력 자료를 만들고, 모형을 구동하고, 결과를 DB에 등록하는 과정까지 맡습니다.

| 프로그램 | 연계 모형 | 역할 | 주기 |
|---|---|---|---|
| `IUF.Simulator.STEPS` | STEPS | 레이더 기반 확률 예측강우 생성 | 10분 |
| `IUF.Simulator.KlimaX` | [KlimaX](../../models/KlimaX10m) | AI 기반 예측강우 생성 | 10분 |
| `IUF.Simulator.HCSURF` | [HC-SURF](../../models/HC-SURF) | 실시간 1D·2D 침수 모의 | 10분 |
| `IUF.Simulator.HI` | [HI](../../models/HI_model) | AI 기반 실시간 2D 침수 모의 | 10분 |
| `IUF.Simulator.HP` | [HP](../../models/HP) | 피해·회복력 평가 | 10분 |
| `IUF.Simulator.PSA` | HC-SURF, HP, [util_loss](../../models/util_loss) | 강우사상 사후분석 (피해·회복력·간접 피해) | 1일 |

[HD](../../models/HD) 모형은 시나리오 모듈로 연계하여, 시나리오별 침수심 결과를 화면에 표출합니다.

### 3. 가시화 모듈

- **3D 디지털트윈 뷰어** (Cesium · 브이월드 기반): 침수심·유속·예측강우 애니메이션, 하수관망 여유 용량(Capacity), 건물별 피해, 행정동별 피해액, 복구 우선순위를 시뮬레이션 플레이어와 함께 보여 줍니다.
- **체감형 가시화** (Unreal Engine 5): 침수 수면을 현실감 있게 표현합니다.
- **모니터링 대시보드**: 실시간 레이더, 한강홍수통제소 알림 정보, 관측소별 차트와 자료 조회, 알람을 제공합니다.

## 운영 방식

MeS는 목적이 다른 두 가지 방식으로 모형을 구동합니다.

| 구분 | 실시간 모듈 | 사후분석 모듈 (PSA, Post Storm Analysis) |
|---|---|---|
| 구동 시점 | 10분 주기 상시 | 강우사상이 끝난 뒤 (배치) |
| 입력 강우 | 관측 강우 + 예측 강우 (KlimaX · STEPS) | 강우사상 전체 기간의 관측 강우 |
| 해석 모형 | HC-SURF · HI | HC-SURF → HP · util_loss |
| 산출물 | 10분 단위 침수심·유속·침수 면적 | 사상 최대 침수심, 직접·간접 피해, 회복력 |
| 목적 | 예보·경보 (재난 대응) | 피해 평가·복구 우선순위 (재난 복구) |

### 실시간 모듈 처리 흐름

1. **자료 수집** — 강우, 레이더, 격자 강수, 하천·관로 수위를 수집해 DB에 적재
2. **전처리** — 관측소 강우를 면적강우로 환산하고 레이더·격자 자료를 준비
3. **강수 예측** — STEPS와 KlimaX로 예측강우 격자 생성
4. **침수 예측·해석** — HI(AI 모형)와 HC-SURF(물리 모형)로 10분 단위 침수심 산출
5. **피해·회복력 평가** — HP로 건물 피해액, 이재민, 회복력, 복구 우선순위 산정
6. **결과 표출** — DB 등록 후 3D 디지털트윈·대시보드·알람으로 제공

### 사후분석 모듈 처리 흐름

1. **강우사상 감지·확정** — 관측 강우를 감시하여 사상의 시작과 끝을 자동 판정
2. **입력 자료 생성** — 사상 전체 기간의 강우 시계열로 모형 입력 파일 작성
3. **침수 해석** — HC-SURF를 소유역별로 병렬 구동
4. **최대 침수심 합성** — 소유역 결과를 합쳐 사상 최대 침수심 격자 생성
5. **피해 평가** — HP(직접 피해·회복력)와 util_loss(간접 피해)를 함께 실행
6. **결과 등록** — DB 등록 후 화면에 표출하고 침수 이력으로 축적

## 자료 연계 표준

모형의 입출력을 격자(ASCII Grid)와 DB 표준 형식으로 정의하여, 다른 플랫폼과 연동할 수 있도록 했습니다.
다른 유역에 적용할 때는 모형 입력 자료를 교체하는 방식으로 확장합니다.

## 검증 및 인증

- **테스트베드 검증**: 도림천 유역과 강남 우수관망에 2022년 8월 집중호우 등 과거 사상을 적용하여 검증했습니다.
- **GS인증 1등급**: 한국정보통신기술협회(TTA)에서 기능적합성·성능효율성·호환성·사용성·신뢰성·보안성·유지보수성·이식성 8개 품질 특성을 시험받았습니다.
- **소프트웨어 저작권**: 데이터 수집 시스템, 침수모의 시뮬레이션 시스템, 모니터링 및 NetCDF 가시화 도구 등을 등록했습니다.
