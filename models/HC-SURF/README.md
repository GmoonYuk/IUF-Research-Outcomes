# HC-SURF — 물리 기반 2차원 침수 해석 모형

| 항목 | 내용 |
|---|---|
| 담당 기관 | (담당 기관에서 기재) |
| 단계 | 침수 해석 |
| 최신 버전 | ver 2.0 |

## 개요

강우와 하수관망, 지형 자료를 이용해 도시 지표면의 흐름을 계산하는 물리 기반 2차원 침수 해석 모형입니다.
배수분구(소유역) 단위로 실행하며, 병렬 계산(OpenMP)을 지원합니다.

## 입력

- 강우 시계열 (10분 간격)
- 지형, 경계 영역, 하수관망, 토지피복·조도 등 유역 기초 자료

## 출력

- 시간대별 침수심 격자 `H_10MIN.asc` ~ `H_360MIN.asc` (10m 해상도, EPSG:5186, 단위 m)
- 최대 침수심 격자 `MAX_H.asc`
- 관망 절점·관로 계산 결과 (CSV)

## 연계

- 최대 침수심 → HP (직접 피해·회복력 평가)
- 시간대별 침수심 → util_loss (간접 피해 산정)
