# util_loss — 간접 피해액 산정 모형

| 항목 | 내용 |
|---|---|
| 담당 기관 | (담당 기관에서 기재) |
| 단계 | 피해 평가 |
| 최신 버전 | ver 1.0 |

## 개요

침수로 사업체가 문을 닫거나 영업이 지체되어 생기는 간접(경제) 피해액을 산정하는 모형입니다.
건물·도로의 직접 피해를 다루는 HP 모형과 짝을 이루어, 하나의 강우 사상에 대한 전체 피해 규모를 파악하는 데 사용합니다.

## 처리 과정

1. 시간대별 침수심 격자에서 최대 침수심을 만듭니다.
2. 건물별 침수심을 구간으로 나누고, 산업별 영업정지·정체 일수를 적용해 영업 손실액을 계산합니다.
3. 전체 손실액을 건물 면적 비율에 따라 개별 건물에 배분합니다.
4. 건물별 손실액을 지도(HTML)로 만듭니다.

## 입력

- HC-SURF의 시간대별 침수심 격자 (`H_10MIN.asc` ~ `H_360MIN.asc`, EPSG:5186)
- 건물 정보(shp), 산업별 종사자·부가가치 통계, 침수심별 영업정지·정체 일수

## 출력

- 건물별 영업 손실 지도 (HTML)
- 산업별·건물별 손실 요약 (CSV, 선택)
