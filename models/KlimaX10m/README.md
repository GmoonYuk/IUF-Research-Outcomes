# KlimaX10m — AI 초단기 강수 예측 모형

| 항목 | 내용 |
|---|---|
| 담당 기관 | 경북대학교 |
| 단계 | 강수 예측 |
| 최신 버전 | ver 4.0 |

## 개요

기상 파운데이션 모델 ClimaX를 서울 지역에 맞게 구성한 AI 강수 나우캐스팅 모형입니다.
최근 1시간의 격자 강수 관측을 입력받아 향후 3시간의 강수 분포를 10분 간격으로 예측합니다.

## 입력

- 기상청 격자 누적강수 NetCDF 자료 (10분 간격)
- 모형 내부에서 서울 영역(100×100 격자, 약 0.5km)을 잘라 내고 누적강수를 10분 구간강수로 변환합니다.
- 실제 모형 입력은 최근 6스텝(1시간)의 구간강수입니다.

## 출력

- 기준시각 +10분 ~ +3시간, 총 18스텝의 예측 강수장
- 형식: ASCII Grid(WGS84) 및 PNG 이미지

## 버전 이력

| 버전 | 주요 내용 |
|---|---|
| ver 2.0 | 강수 예측 초기 버전 |
| ver 3.0 | 10분 해상도, NetCDF 전처리 내장, 하루 단위 실행, +1시간 예측 |
| ver 4.0 | 준실시간 실행(필요 구간 자료만 사용), +3시간 예측 |

## 연계

예측 강수장은 침수 모형(HI_model, HC-SURF)의 강우 입력으로 연계할 예정입니다.
