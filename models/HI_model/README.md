# HI_model — AI 침수 예측 모형

| 항목 | 내용 |
|---|---|
| 담당 기관 | (담당 기관에서 기재) |
| 단계 | 침수 예측 |
| 최신 버전 | v2 |

## 개요

강우 시계열만으로 침수심 분포를 추론하는 딥러닝 기반 대리모형입니다.
물리 모형으로 수 분이 걸리는 침수 해석을 수십 초 안에 근사하므로, 10분 주기의 실시간 침수 예측에 사용합니다.

## 입력

- 강우 시계열 CSV (`datetime`, `Precipitation` 열, 10분 간격)
- 실시간 운영에서는 관측 강우와 예측 강우를 이어 붙인 37스텝(약 6시간)을 사용합니다.

## 출력

- 시간 스텝별 침수심 격자 (ASCII Grid, 5m 해상도, 단위 m)
- 파일명은 시각에 따라 자동으로 붙습니다. 예: `HI_20220808_1900.asc`
- 기준값(기본 0.05m)보다 얕은 침수심은 0으로 처리합니다.

## 실행

```
HI_model.exe --rainfall rainfall.csv --output output_folder/
```

| 인자 | 필수 | 기본값 | 설명 |
|---|---|---|---|
| `--rainfall` | O | - | 강우 CSV 파일 |
| `--output` | O | - | ASC 출력 폴더 |
| `--threshold` | X | 0.05 | 침수심 기준값 (m) |
